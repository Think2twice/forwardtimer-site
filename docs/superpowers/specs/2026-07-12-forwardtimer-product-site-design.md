# ForwardTimer 产品站设计说明

## 目标

建立一个独立、轻量、可供 App Store 审核和用户访问的 ForwardTimer 静态站。站点需要同时承担产品介绍、使用支持和隐私声明三个任务，不依赖已有个人主页，也不暴露个人联系方式或服务器信息。

## 方向比较

1. 纯文档页：上线最快，但不能呈现 App 的产品气质。
2. 重营销 Landing Page：视觉冲击更强，但不符合 ForwardTimer 安静、克制的工具属性。
3. 克制的产品叙事：用留白、真实界面和少量动效表达产品，同时让支持与隐私内容保持清楚可扫读。

采用第 3 种。用户已明确指定 Apple 风、参考 Paste 的克制留白与产品展示感，并要求不中断创意澄清，因此该方向视为已批准。

## 视觉规格

- 气质：高级、安静、可信赖，不做营销页式夸张渐变。
- 识别：沿用 App 的蓝色计时面板与橙色状态点，不复制第三方品牌素材。
- 排版：以中文大标题和宽松行距建立层级；产品页大留白，文档页收窄阅读宽度。
- 产品证据：使用真实 iPhone 截图和真实 App 图标，截图明确标注为 App 实际界面。
- 动效：只有首屏呼吸光、滚动显现和悬停反馈；尊重 `prefers-reduced-motion`。

## 信息架构

- 首页：产品主张 → 真实界面 → 核心能力 → 本地隐私承诺 → 支持/隐私入口。
- 支持页：快速开始 → 常见问题 → 排障清单 → 数据与权限说明。
- 隐私页：结论摘要 → 本地数据 → 权限 → 不收集/不共享 → 网站边界 → 更新方式。

## 隐私事实

- 无需账号。
- 不收集个人数据，不接入分析或广告 SDK，不追踪用户。
- 计时、分段、历史和提醒配置保存在设备本地；主 App 与扩展只通过同一 App Group 共享必要状态。
- 核心功能离线可用；本地通知权限可由用户随时在系统设置中撤销。

## 技术方案

- 独立公开 GitHub 仓库，GitHub Pages 从 `main` 根目录发布。
- Cloudflare DNS-only CNAME 指向 `think2twice.github.io`。
- 无构建步骤、无远程依赖、无追踪脚本。
- 语义化 HTML、键盘焦点、可访问对比度、移动端响应式。

## 验收

- 本地 HTML 链接和静态资源检查通过。
- 390px、768px、1440px 视口无横向溢出。
- `/`、`/support/`、`/privacy/` 在 GitHub Pages 与自定义域名均返回 200。
- GitHub Pages 证书覆盖自定义域名并启用 HTTPS 强制跳转。
